## 公网读取风险

默认127.0.0.1监听只限制直接连接；隧道或反向代理可把外部访问带进来。/api/town-snapshot、/api/town-events、/api/town-agents、/api/town-services、/api/town-dingtalk/bindings以及配置后的日志流，可能返回任务摘要、进程状态、内部端口、会话/机器人标识和原始日志。

建议使用访问网关或反向代理统一认证，覆盖SSE与日志路径。不要只给POST设置写入令牌。公开展示若有需求，应另外提供字段白名单投影，禁止直接公开完整运行账本。
