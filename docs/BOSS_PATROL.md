# 老板巡视环境动画

## 节奏与边界

- 在有真实数据和真实角色的实时页面启用，首次等待45分钟，之后以每轮开始时间为基准相隔45分钟。
- 老板不属于真实智能体，不占工位、不上报任务、不进入API或负载统计，不发送钉钉消息。
- 下一次时间保存在当前浏览器localStorage中，刷新不会重新从零计时；存储不可用时退化为当前页面计时。
- 随机项为本轮互动员工、双方胜负和视觉图标。间隔为45分钟，不是每帧随机触发。
- 这是页面环境动画，不是服务器调度任务；多浏览器没有全局同步。后台页/暂停后恢复时只启动一轮，不补播多次。

## 巡视流程

1. 西服、领带、手拿水杯的老板从办公区下方门口进入。
2. 逐位选择可达员工，按较短路线走到附近通道；真实员工和环境员工均包含。
3. 每位员工停留约1秒，双方头顶切换“开会”和“大饼”元素。
4. 随机一位员工增加约2秒卡通打斗，随后继续拜访未巡视员工。
5. 巡视结束，沿通道回到同一个门口并离开画面。

门内行走使用原有四邻接网格寻路和家具避障，门外进入/离开使用门口短过渡。不会从地图中间突然生成，也不会用一条直线穿越桌柜。

员工巡视时短暂停下画面动作，业务数据仍正常接收；交流和打斗结束后恢复最新业务状态与路径。已有的短时视觉指令可能被巡视打断，不会改变后台任务结果。

## 卡通打斗

- 先沿可达路线移动到有空间的并排位置，避免站在桌面或重叠的窄缝中。
- 双方初始血条100，交替命中，显示掉血数字、命中闪光、受击后退与轻微画面抖动。
- 任意一方血条归零立即结束打击，短暂显示零血后收起血条。
- 随机可能是员工或老板先归零。老板会按卡通表现恢复并继续巡视，不会影响实际角色状态。
- 一轮最多一场打斗，其他员工只有约1秒交流。
- 减少动态效果设置关闭抖动与CSS击打位移；暂停时动作计时、打斗和画面抖动一起暂停。

## 稳定性

- 巡视期间暂停环境员工数量的随机增减，避免目标无故消失；用户主动关闭环境员工时会跳过已移除目标。
- 员工不可达或已经离开时跳过，不让老板卡在家具中。
- 地图工位数量重建会结束当前巡视，清除员工锁定和血条。
- 一轮有总时长保护，避免异常状态永远留在巡视中。
- 原有API、日志、北京时间24小时制保持不变。

## 验证与预览

自动化覆盖45分钟触发阈值、逐员工可达路线、随机打斗只发生一次、双方任一归零、退出门口、员工状态恢复，以及环境员工参与巡视与打斗。

实际浏览器验证时，在开发者控制台调用 `startBossPatrol(Date.now())` 可立即预览当前轮（不改后台数据），无需等待45分钟。此调用仅用于本地验收，不是用户业务接口。
